# Paperback MAL Tracker (0.8)

A working [MyAnimeList](https://myanimelist.net/) tracker extension for [Paperback](https://paperback.moe/) **0.8** (the App Store version).

Based on the MyAnimeList tracker from [Paperback-iOS/extensions](https://github.com/Paperback-iOS/extensions) (GPL-3.0), with fixes for login/token refresh and chapter syncing.

## Development

```sh
npm ci
npm run bundle   # build into bundles/
npm run serve    # serve locally; add http://<your-lan-ip>:<port> as a repository in Paperback
```
